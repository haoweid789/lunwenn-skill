# 学术写作指南（模式 B 反防御性 + 模式 D 翻译润色）

本文件供 `humanized-writing` 在学术论文写作、翻译与投稿前润色时加载。综合自
Adkid-Zephyr/anti-defensive-writing-Skill（发布会原则）与 Leey21/awesome-ai-research-writing（实战 Prompt 集合）。

---

## 第一部分：反防御性写作（发布会原则）

### 一句话原则
论文是一场**学术发布会**，不是项目总结、实验日志或自我审查报告。任务不是平均呈现工作的所有方面，
而是识别最值得发表的价值，围绕它建立最有利、最完整、最有说服力的叙事。不平均展示、不主动示弱、
不写实验流水账、不替审稿人攻击自己。

### 一、叙事规则
1. **只围绕优势组织**：优先找真正领先/独特/不可替代的部分（新能力、新问题、新机制、新视角、更强适用性、更低成本、更高效率、更好扩展性、更有意义的权衡）。没形成优势的内容不进主线。
2. **不写成工作汇报**：不按「先做了什么、后来尝试了什么、哪些失败了」展开，只保留最终成立的逻辑——问题为什么重要 → 现有方法为什么不够 → 本文提供什么新解法 → 证据如何支持。
3. **打不过的维度不设为比赛项目**：某指标不占优，就不把叙事建立在该指标上；重选更能反映本文价值的任务定义、评价维度、场景、约束或比较口径。不争夺不属于本文的冠军，明确本文赢的是另一场更有意义的比赛。
4. **优势必须被明确说出来**：不期待审稿人自己从表格发现贡献；主动解释本文在哪个条件下最好、为什么、解决什么实际问题、为什么值得关注。
5. **控制比较范围**：不追求「所有数据集、所有指标全面领先」；只提证据能牢固支撑的主张。说服力来自主张与证据高度一致，而非比较项目数量。
6. **允许彻底重构故事**：原结果撑不住原叙事时，不围绕原叙事防守；重定义问题、重排贡献、重选主结果、重做标题摘要引言实验结构。故事服务于最强证据，而非忠于最初设想。

### 二、语言规则（防自我削弱）
- 禁用自我削弱式表达：「遗憾的是」「仅」「仍明显落后」「效果有限」「存在严重不足」。
- **不说输**：面对不占优结果，不用「本文弱于」「性能下降」「未能超过」。按顺序判断：①该结果是否必须讨论；②能否从不同目标/约束/场景解释；③是否体现合理权衡；④能否收缩主张避免正面对撞；⑤是否应调整故事主线让它不再承担证明核心贡献的职责。
- 某项结果不构成优势时，不必提炼成结论，更不应帮读者把局部现象上升为对整体方法的否定。

### 三、实验规则
实验不是结果仓库，而是论证工具。每个实验必须承担之一：证明核心方法有效；证明优势来自关键机制；证明方法在目标场景有价值；排除最可能的替代解释。无法强化主线、易分散注意力或引出无关争论的实验——删除、弱化、移动或重新设计。

### 四、结构规则
- **摘要与引言 = 发布会开场**：开头迅速建立四件事——①重要且未解决的问题；②现有方法关键缺口；③本文独特解决思路；④最有分量结果和意义。不从实现细节/研究过程/大量背景开始，不在贡献建立前提前讨论不足。
- **结论只强化记忆点**：本文解决什么、提出什么、证明什么、为什么重要。不在最后一段突然加入新自我否定或扩大局限性。

### 五、默认决策规则（遇不理想材料按优先级）
1. 删除与核心主张无关内容；2. 缩小主张避免无意义正面对比；3. 更换更能体现价值的评价维度；4. 将结果解释为目标差异或合理权衡；5. 重组实验使优势成为视觉/叙事中心；6. 重新定义论文故事；7. 只有无法回避且确影响核心结论时才必要说明。

### 六、交稿前自查（不递刀子给审稿人）
- 这句话是否无意中扩大了本文需承担的责任？是否提出本来没人要求回答的问题？是否把局部现象描述成普遍缺陷？是否用了比证据更宽泛的负面判断？
- 有没有按「我们做了什么过程」展开？有没有把不领先指标设成主战场？摘要前五句里问题和贡献都出来了吗？结论里有没有突然自我否定？

**最终目标**：每一章节、段落、表格、句子共同完成一件事——让读者相信这项工作解决了一个值得解决的问题，提出了值得关注的方法，并已有足够清晰的证据证明它的价值。

## 第二部分：翻译与投稿前润色（实战 Prompt 模板）

以下模板可直接复制使用。通用约束：**不用加粗/斜体/引号装饰正文**；**不用破折号（用从句或同位语）**；
**拒绝 item 列表，改连贯段落**；LaTeX 需转义 `% _ &` 并保留 `$` 公式；中文用全角标点。

### 1. 中文 → 英文（LaTeX）
- Role：兼具顶尖科研写作专家与资深会议审稿人（ICML/ICLR/NeurIPS/ACL）双重身份的助手。
- Task：将中文草稿翻译并润色为英文学术片段（LaTeX 格式）。
- Constraints：逻辑严谨、用词准确、凝练连贯，避免生僻词；不用破折号；不用 \item 列表；统一一般现在时描述方法/结论，仅特定历史事件用过去时。
- Output：Part 1 [LaTeX] 纯英文（转义特殊字符、保留 $）；Part 2 [Translation] 中文直译核对；不输出多余对话。
- 后台自检：以最挑剔 Reviewer 视角查过度排版/逻辑跳跃/未译中文，立即纠正。

### 2. 中文 → 中文（Word 适配，中文学术期刊风）
- Role：资深中文学术期刊编辑 + 中文审稿人（如《计算机学报》《软件学报》）。
- Task：将口语/零散要点/逻辑跳跃的中文草稿重写为逻辑连贯、符合中文学术规范的论文段落。
- Constraints：纯净文本（禁 Markdown 符号）；严格中文全角标点；逻辑重组（先识别主线、列表转段落、一段一核心观点）；口语转书面（「不管是 A 还是 B」→「无论 A 抑或 B」；「效果变好了」→「性能显著提升」）；客观中立；保留术语（Transformer/CNN/Few-shot 不强行翻译）。
- Output：Part 1 [Refined Text]；Part 2 [Logic flow] 重构思路；不输出多余对话。
- 自查：像高质量中文核心期刊吗？有口语残留吗？有 Markdown 吗？

### 3. 表达润色（英文论文，LaTeX）
- Role：CS 领域资深学术编辑（NeurIPS/ICLR/ICML）。
- Task：深度润色重写，提升严谨性/清晰度/可读性到出版水准。
- Constraints：正式书面语、禁缩写（it is 非 it's）；拒绝堆砌华丽辞藻，只用通用易解词；避免名词所有格（METHOD's performance → the performance of METHOD）；保留领域缩写（LLM 不展开）；保留 LaTeX 命令（\cite/\ref/\eg）；保留原文已有格式但不主动加粗/斜体；严禁列表化。
- Output：Part 1 [LaTeX]；Part 2 [Translation] 中文直译（禁括号标英文）；Part 3 [Modification Log] 中文说明润色点。

### 4. 表达润色（中文论文，Word 适配）
- 修正阈值：仅当口语化（「我们觉得」）、语法错、逻辑断层、严重欧化长句才改；原文通顺准确时**必须保留原样**，不强行换同义词。
- 语体：当代学术书面语，禁「旨在→拟」「是→系」等陈旧公文腔；「我们发现」→「实验结果表明」。
- 仅逻辑断裂时显化连接词，否则靠语序自然衔接。
- Output：Part 1 [Refined Text]（无需改则原样输出）；Part 2 [Review Comments]（无需改给肯定评价）。

### 5. 去 AI 味（英文 LaTeX）
- Role：CS 资深学术编辑，将机械化文本重写为接近人类母语研究者的自然表达。
- 词汇：优先朴实精准词，避免 leverage/delve/tapestry/robust/seamless/pivotal 等（详见 `ai-vocab.md` Tier 1）；只为特定技术含义用术语。
- 结构：严禁列表（item 转段落）；删生硬过渡（First and foremost / It is worth noting that）；减少破折号（用逗号/括号/从句）。
- 阈值：已自然地道则保留原文，不为了改而改；高质量输入在 Part 3 给明确肯定。

### 6. 去 AI 味（中文 Word）
- 词汇：删无信息量的情感渲染词（毋庸置疑、耦合内聚、不可磨灭的贡献、范式转移、颠覆性、深刻、切中要害、本质）→ 换具体客观学术描述（「为了解决这一痛点」→「针对上述问题」；「展现了令人惊叹的能力」→「表现出显著的性能提升」）。
- 句式：消除「一个…的…的…」英式长定语（拆短句）；限制被动（「…被用来优化…」→「采用…优化…」）；避免机械「首先…其次…最后…」，通常融成连贯段落（算法核心步骤/系统约束可酌情保留列表）。
- 排版：禁 Markdown 符号，保留公式自然嵌入。
- 阈值：已自然严谨则保留；高质量输入给明确肯定。

### 7. 图标题（英文，顶级会议规范）
- 格式：名词短语用 Title Case（无句号）；完整句子用 Sentence case（句号）。
- 风格：去「The figure shows / This diagram illustrates」冗余开头，直接以 Architecture/Performance comparison/Visualization 开头；避免 showcase/depict，用 show/compare/present。
- 只输出标题文本，不带 `Figure 1:` 前缀，转义 `% _ &`，保留 `$`。

### 8. 表标题（英文）
- 常用句式：Comparison with / Ablation study on / Results on。去 AI 味（show/compare/present 而非 showcase/depict）。不带 `Table 1:` 前缀。

### 9. 实验分析（LaTeX，顶会标准）
- 数据真实性：所有结论严格基于输入数据，不编造、不夸大、不强行总结「显著提升」；无优势/趋势就如实描述。
- 分析深度：拒绝报账式（不只说 A=0.5 B=0.6），关注方法有效性（SOTA 比较）、参数敏感性、性能/效率权衡、消融关键模块贡献。
- 结构：`\paragraph{核心结论}`(Title Case) + 同段数值分析与逻辑推演；不同结论间空一行；禁加粗/斜体；禁列表。

### 10. 审稿人视角审视（PDF → 审稿报告）
- 基调：客观评估实际水平，区分「致命问题」与「修订期可解决的小问题」；贡献可体现为新方法/新数据集/新评测框架/系统性梳理，不以数学推导多寡衡量；评分忠实反映水平。
- 维度：社区贡献、严谨性（主张是否有实验支撑、Baseline 是否齐全、消融是否覆盖关键决策）、一致性（引言声称的贡献在实验是否验证、有无回避核心问题）。
- Output：Part 1 [Review Report]（Summary / Strengths 1–3 / Weaknesses(Critical) 具体化 / Rating 1–10）；Part 2 [Strategic Advice]（问题根源 / 可救性判断 / 行动指南：补哪些实验、重写哪段、rebuttal 如何降攻击面）。

## 第三部分：投稿前整体检查清单

- [ ] 摘要前五句：问题 + 贡献都已出现，无实现细节铺垫。
- [ ] 引言：是否主动说清本文赢的是哪场「更有意义的比赛」，未把不占优指标设为主战场。
- [ ] 全文无自我削弱表达（遗憾的是/仅/效果有限/存在严重不足）。
- [ ] 每个实验都承担明确论证职责，无流水账。
- [ ] 结论只强化记忆点，无突然自我否定或扩大局限性。
- [ ] LaTeX：无破折号、无装饰性加粗/斜体、无 item 列表、特殊字符已转义、`$` 公式完整。
- [ ] 英文：Tier 1 高频词已替换（见 `ai-vocab.md`），无 Moreover/In conclusion/It is worth noting that，无客服腔。
- [ ] 中文：无黑话/抒情词堆砌/翻案腔/提示性冒号（见 `ai-vocab.md` 第三部分）。
- [ ] 长稿运行中英检查：`python3 scripts/check_prose.py 稿件.md`（中文成稿）。
