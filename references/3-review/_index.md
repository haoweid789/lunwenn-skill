# 3 审稿与核验族

**第一件事先分清方向**，这四个字在这里指两件相反的事：

```
用户是被审的一方（收到了审稿意见）
   → response/            逐点回应
   → response-word/       要中文 SCI 回复信（两阶段 Word）
   → peer-review/         想在投稿前先自审一遍

用户是审的一方（要给别人提意见）
   → peer-review/         单视角模拟审稿
   → panel/               五座席评审团（要挑致命问题）
   → review-paper/        九准则 + 核验 + 期刊契合度

用户要产出一篇综述文章
   → literature-review/   这是"写 review"，不是"审 review"

用户只要核验引文/论断真伪
   → citation-check/      最严的双通过门禁
   → ref-verifier/        参考文献真伪交叉验证
```

## 八个模块

### `peer-review/` Nature 视角模拟审稿 — 主干
**精华**：三段结构 — **significance / validity / major-minor**。它带来源层级（哪些说法只能引官方政策、哪些可以引语料推断）和红线清单。

**用途切换**：既可用于投稿前自审，也可用于给别人提意见。区别只在"stance"——自审时它会说得更狠。

### `review-paper/` 九准则深度审 — 主干
**精华**：九条准则 + 严重度分级，比上者多出两个阶段：
- **事实与文献核验**：不只评逻辑，还去查引用是否真的支撑那句话
- **期刊契合度**：这篇适不适合这本刊，很多拒稿真实原因是这个

**选哪个**：要快、要 Nature 味 → `peer-review`；要彻底、要挑出会被拒的硬伤 → `review-paper`。

### `panel/` 五座席评审团 — 保留
**精华**：Journal-Fit Reviewer + 3 个同行角色 + **Devil's Advocate**（专门唱反调的那个）。每个座席有字段专属标准，还有校准模式防止评审太松或太狠。

**代价**：45 KB / 28 文件，最重。只在"要模拟真实审稿会"或"要挖出深层问题"时用。

### `response/` 逐点回应 — 主干
**精华**：核心判断是「**这件事能不能靠解释解决**」——
- 能：写解释 + 补引用 + 调整措辞
- 不能：必须补实验，那就明确列出要补什么

它不会把"补不了"包装成"已解释"。

### `response-word/` 中文 SCI 两阶段回复 — 保留
**精华**：**先出一份标红待办的 Word，材料齐了再出正式回复**。这个两阶段设计解决一个真实痛点：审稿人问的问题里总有几个当前材料解决不了，如果一次性写完回复，就得硬编或含糊。它强制把"待解决"和"已解决"分开。

带学术 Humanizer，最终只交第二份 Word。

### `citation-check/` 引文论断核验 — 主干
**精华**：**视觉 + 搜索双通过门禁** ——
1. 论断穷尽抽取（不漏句）
2. 源权威性分级（官方政策 / 期刊 / 预印本 / 新闻，权重不同）
3. **数字精度规则**（统计值保留几位、百分比的基准是什么）
4. 平局裁决规则
5. 视觉数据核验（图里的数字也要核）

这套是全包最严的核验，`nature-citation` 和 `phd-skills/paper-verification` 的精华都并到了这里。

### `ref-verifier/` 参考文献真伪 — 保留
**精华**：多来源交叉验证，带 56 条实测过的工作流和**已知局限说明**（哪些类型它验不准）。适合怀疑参考文献被编造（AI 生成的稿子常犯）。

> 补充（原 `nature-academic-search` 的独有功能）：**MeSH 策略构建**用于 PubMed 精准检索；**引文影响审计**用于评估某篇文献的实际影响力而非引用数。

### `literature-review/` 写综述文章 — 保留
**精华**：它有一道**硬门槛**——Word 数与文献数量不达标不往下走，防的是"综述写成读后感"。五步：确定问题与顶刊参照 → 检索筛选 → 提取评价证据 → 综合论证 → 核验交付。

## 合并进来的

| 原模块 | 精华去哪了 |
|---|---|
| `nature-citation` | 论断-来源映射思路 + 引用管理导出 → `citation-check/` |
| `phd-skills/paper-verification` | 三个核验维度 → `citation-check/` 的检查表 |
| `nature-academic-search` | MeSH 策略、引文影响审计 → 本文件上方补充 |

## 坑

- **别用 `panel/` 做投稿前自审**。五个座席会给出互相冲突的意见，自审要的是"最可能被拒的点"，`review-paper/` 的严重度分级更直接。
- `citation-check` 需要联网搜索。离线时退到 `ref-verifier` 的多来源交叉验证（它也联网，但容错更好）。
- `response/` 与 `response-word/` 不要同时跑——前者是策略，后者是成稿。先用前者定策略，再用后者出 Word。
