# 4 图表族

## 先分清三种「要图」

```
要一张新的图（我有数据）
   → data-figure/      原创出版级图
   → viz-code/         只要代码，我自己调

要复现一张看到的图（版式要对）
   → reproduce-figure/ 六步锁死版式，含"跑通参考代码"硬要求

要一张图变成可编辑的（图片→PPT/AI）
   → reconstruct-su7/  付费 API，按张计额
   → image2ppt/        对象级还原（免费/本地）

要判断图好不好
   → rubric/           18 条评分
```

## 七个模块

### `data-figure/` 原创出版级图 — 主干
**精华**：Python/R 出图，72 个文件是期刊尺寸、字体、配色、线宽的真实资产。不是"给个 matplotlib 模板"，是按目标期刊的物理尺寸和字号反推画布。

### `reproduce-figure/` 六步复现 — 主干
**精华**：六步里第二步是别的都没有的硬要求 ——
1. 确定图要回答什么问题
2. 选择、阅读并**锁定**参考图
3. **获取数值，实际编写并运行参考复现代码**（不是看一眼就改）
4. 核验视觉一致性，不通过就回去改
5. 复用通过核验的代码，替换成自己的数据
6. 重跑、核查、发布

第 3 步是灵魂：**必须先把参考图复现出来**，否则你改的是自己的想象。这道关卡掉了绝大多数"照着画但画不像"的情况。

### `viz-code/` 可视化代码 — 保留
Python/MATLAB 代码生成，只管出代码不管审美。适合"我知道要画什么，你给我能跑的代码"。

### `reconstruct-su7/` 图片→可编辑 — 主干（付费）
**精华**：把位图科研图还原成**文字可编辑**的 PowerPoint 或 Adobe Illustrator 矢量对象，按路径回放绘制。可应对约 90% 常见情况。

**收费结构**（必须先用说清楚，母 `SKILL.md` 红线第 4 条）：

| 档位 | 出处 | 额度 | 耗时 | 什么时候用 |
|---|---|---|---|---|
| 标准 | `reconstruct-su7/` | 20/张 | 约 3 分钟 | 默认，90% 情况够 |
| 高质 | `reconstruct-su7/sub/cell_su8/` | **3/张**（单位不同，见原说明） | 约 5 分钟 | 仅当标准档出现扭曲或马赛克 |
| 深嵌 | 原 `cell-cns-figure` 2 号 | 45/张 | 更久 | 高嵌套文件、极重美观 |

> **合并说明**：原 `cell_su8` 与 su7 功能完全相同，唯一差异是去水印更强 → 作为参数保留在 `sub/`。原 `cell-cns-figure` 是同一个商业服务的另一个入口（1 号 20 额度 / 2 号 45 额度）→ 其选档规则并入本表，目录不再复制。

### `image2ppt/` 对象级还原 — 保留
**精华**：把幻灯片截图、扫描 PDF、纯图 PPTX 还原成**对象级可编辑** PPT，不是贴图。90 个文件含各平台绘制路径矩阵。跟 su7 的区别：这是本地/免费路线，su7 是付费高保真路线。

### `paper2ppt/` 论文→组会 PPT — 保留
带我源图与演讲备注的中文 PPTX。适合组会汇报，不是投稿用。

### `rubric/` 18 条图评分 — 保留
**精华**：18 条规则 + 严重度分级 + 渲染检查。用来**判断**图而不是画图。自查和互评都能用。

## 坑

- **`reconstruct-su7` 是付费的**。标准档每张约 1 额度（超过 1 额度时须先报「本张预计消耗 N 额度，是否继续？」），
  `sub/cell_su8/` 高质档每张 3 额度，原 `cell-cns-figure` 深嵌档 1 号 20 / 2 号 45 额度。执行前必须报价，且优先试 1 张再批量。
  完整规则（含推广话术禁用、降级路径、API Key 处理）见 [`_LOCAL_POLICY.md`](_LOCAL_POLICY.md)。
- su7 的输出来自识别，**文字可能被认错**。它的流程里有"识别输入与文字对齐"一步，别跳过。
- `data-figure` 和 `reproduce-figure` 的选择标准是**有没有参考图**。有参考图就不要用 data-figure 自由发挥，会一直改不到满意。
- 图片可能被"微调"——su8 档说明里明写"图片可能微调"。做定量图（柱高、坐标值必须精确）时不要用重建路线，用代码重画。
